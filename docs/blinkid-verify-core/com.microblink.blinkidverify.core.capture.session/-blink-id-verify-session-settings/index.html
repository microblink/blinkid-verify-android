consent

val consent: ExternalConsentObject?

End-user consent for cloud processing. When set, it is passed into native native getResult so the generated request payload contains the consent object. Set it only when consent is already available before the session starts (client-managed consent flow). Sessions launched through the scanning screen receive consent from BlinkIdVerifyConsentUxConfig instead, via com.microblink.blinkidverify.core.capture.session.BlinkIdVerifyScanningSession.setConsent or com.microblink.blinkidverify.core.capture.session.BlinkIdVerifyScanningSession.setConsent.
