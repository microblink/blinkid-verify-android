End-user consent for cloud processing of identity data, as accepted by the BlinkID Verify API.

The SDK never communicates with the Consent Management Service (CMS). Consent is recorded by the BlinkID Verify backend, which forwards it to the CMS. The only responsibility of the SDK is to collect consent (or accept one collected by the integrator) and to provide this object during native getResult payload generation.

Instances are created either by:

  • the built-in consent UI when configured with com.microblink.blinkidverify.ux.consent.BlinkIdVerifyConsentUxConfig.RequireConsent, or

  • the integrator, when consent is collected on their own UI (client-managed consent flow), and handed over through com.microblink.blinkidverify.ux.consent.BlinkIdVerifyConsentUxConfig.ProvideExternalConsent or com.microblink.blinkidverify.core.capture.session.BlinkIdVerifySessionSettings.consent.

Field definitions follow the Verify v3 cloud API consent model.
