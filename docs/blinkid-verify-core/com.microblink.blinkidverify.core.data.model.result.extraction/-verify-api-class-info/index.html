VerifyApiClassInfo

@Serializable
data class VerifyApiClassInfo(val country: String?, val region: String?, val type: String?, val countryName: String?, val isoAlpha3CountryCode: String?, val isoAlpha2CountryCode: String?, val isoNumericCountryCode: String?)

Document class information as returned by the Verify HTTP API (v2/v3).

This is a data transfer model: the backend sends flat string values for country, region, and type (known enum names or future unknown strings). It must not be confused with com.microblink.blinkidverify.core.result.classinfo.DocumentClassInfo, which is the SDK domain model populated from native capture (id + rawValue).
