NativeSerializedVerifyPayload

data class NativeSerializedVerifyPayload(val imageFirstSide: ByteArray?, val imageSecondSide: ByteArray?, val imageBarcode: ByteArray?, val configuration: String, val consent: String?, val traceId: String?, val sdkMetadata: String)

BlinkID Verify v3 multipart/form-data parts produced by the native payload generator.

Image parts are JPEG bytes. configuration, consent, and sdkMetadata are JSON strings. traceId is optional. Submit these parts with com.microblink.blinkidverify.core.BlinkIdVerifyClient.verify.
