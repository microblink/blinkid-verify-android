ProvideExternalConsent

data class ProvideExternalConsent(val consent: ExternalConsentObject) : BlinkIdVerifyConsentUxConfig

Skips the SDK consent UI. The provided consent is added to the generated request payload as-is.

The consent object must match the Verify v3 consent model, including ExternalConsentObject.givenOn, which the integrator sets when consent was collected on their own UI.
